# Contributing to Project Pilot

Thanks for your interest. This repository currently contains a **public, sanitised project plan**; its implementation is not yet available here.

## Helpful contributions now

- Report a reproducible **non-sensitive** problem or usability requirement.
- Improve public documentation and acceptance criteria.
- Suggest small, testable improvements to project progression and recovery.
- Review release blockers in the public issue tracker.

## Please wait on implementation contributions

The source redistribution and project licence decision are still pending. Please do not submit copied code, private development history, or third-party sources unless rights and provenance can be established. A contribution policy for code will be published alongside the initial licensed source release.

## Before opening an issue or pull request

1. Check for an existing issue.
2. State the expected behaviour, current behaviour, and a minimal public-safe reproduction.
3. Strip out credentials, file paths revealing private infrastructure, personal data, and private repository identifiers.
4. Keep changes focused and describe what was tested.
5. Distinguish offline tests from verified Hermes runtime tests.

See [security guidance](SECURITY.md), [roadmap](docs/ROADMAP.md), and [release gates](docs/RELEASE-GATES.md).
